## SaaS / 工具产品

### Linear
- **URL**：linear.app
- **风格对应预设**：A 极简黑白
- **可借鉴模式**：
  - Hero 区：左文右图，产品截图带细边框无阴影
  - 配色：纯黑强调色 + 灰阶，无多余彩色
  - 导航栏：半透明白底 + blur，滚动时变实色
  - 字体：Inter，标题字重 700
  - 卡片：边框定义，无阴影
- **为什么好**：极致克制，黑白灰三色搞定一切，信息层级完全靠字号字重

### Notion
- **URL**：notion.so
- **风格对应预设**：B 现代暖调
- **可借鉴模式**：
  - 配色：暖白底（#fffdf9）+ 深色文字，无强对比
  - 圆角：适中，所有元素 8px 左右
  - 图标：统一单色灰色，极简线条
  - 间距：宽松，呼吸感强
  - 动效：几乎无动画，仅 hover 微交互
- **为什么好**：温暖不冷漠，像纸张一样舒服，适合长时间使用

### Stripe
- **URL**：stripe.com
- **风格对应预设**：B 现代暖调（偏紫强调色）
- **可借鉴模式**：
  - Hero 区：大标题 + 渐变网格背景（注意：Stripe 的渐变是同色系深浅，不是跨色相对比）
  - 卡片：悬浮时上移 4px + 淡阴影，过渡 200ms
  - 代码示例：深色代码块配语法高亮，专业感强
- **为什么好**：技术感与友好感平衡得好，面向开发者但不冷硬

## 设计 / 创意产品

### Vercel
- **URL**：vercel.com
- **风格对应预设**：A 极简黑白（深色模式为主）
- **可借鉴模式**：
  - 配色：黑底白字为主，强调色用白色
  - 字体：Geist（Vercel 自有字体），标题用等宽或 sans
  - Hero：大字号标题 + 代码/终端风格视觉
  - 导航：极简，只有 Logo + 几个链接
- **为什么好**：技术品牌的标杆，黑白也能做出高级感

### Apple
- **URL**：apple.com
- **风格对应预设**：C 高端深色
- **可借鉴模式**：
  - 配色：深色背景 + 高饱和产品图
  - 排版：超大标题 + 大量留白
  - 动效：滚动视差，产品图随滚动变换
  - 按钮：圆角较大（12px+），纯色填充
- **为什么好**：用留白和大图营造高级感，不靠装饰

### Arc
- **URL**：arc.net
- **风格对应预设**：C 高端深色
- **可借鉴模式**：
  - 配色：深色 + 渐变强调（但只用在小面积）
  - 字体：标题用衬线，正文无衬线
  - 视觉：大量产品动图/视频展示
- **为什么好**：浏览器产品做出了时尚品牌的感觉

## 内容 / 媒体平台

### Medium
- **URL**：medium.com
- **风格对应预设**：G 文艺编辑
- **可借鉴模式**：
  - 排版：衬线字体正文，行高宽松（1.75+）
  - 文章宽度：限制在 700px 左右，易读
  - 配色：白底黑字，仅链接用绿色
  - 首字下沉：文章开头第一个字放大
- **为什么好**：阅读体验标杆，排版规则值得全文照搬

### Substack
- **URL**：substack.com
- **风格对应预设**：G 文艺编辑
- **可借鉴模式**：
  - 配色：米白底 + 墨色文字
  - 字体：标题衬线，正文无衬线
  - 卡片：文章卡片只有标题 + 摘要 + 作者，无多余装饰
  - 圆角：极小（2px），偏直角
- **为什么好**：内容平台的克制典范，让文字本身成为主角

## 电商 / 消费品牌

### Apple Store
- **URL**：apple.com/store
- **风格对应预设**：C 高端深色（部分页面浅色）
- **可借鉴模式**：
  - 商品卡片：大图 + 产品名 + 价格，无多余描述
  - 布局：大图网格，间距大
  - 配色：白色背景为主，产品图自带色彩
- **为什么好**：商品展示的极致，让产品自己说话

### Glossier
- **URL**：glossier.com
- **风格对应预设**：B 现代暖调（粉色系）
- **可借鉴模式**：
  - 配色：粉色强调色 + 暖白底
  - 字体：圆润无衬线
  - 摄影：自然光、生活化，不棚拍
- **为什么好**：消费品牌的温暖感，不是冷冰冰的电商

## 开发者 / 技术产品

### GitHub
- **URL**：github.com
- **风格对应预设**：A 极简黑白（深色模式）
- **可借鉴模式**：
  - 配色：Primer 设计系统，灰阶为主
  - 代码：等宽字体，语法高亮配色克制
  - 表格：信息密度高，紧凑间距
  - Badge：小标签用背景色 + 文字，不用边框
- **为什么好**：开发者工具的信息密度标杆

### Tailwind CSS
- **URL**：tailwindcss.com
- **风格对应预设**：A 极简黑白 + 青色点缀
- **可借鉴模式**：
  - 配色：深色模式为主，青色（teal）作为唯一强调色
  - 代码示例：深色代码块，关键代码高亮
  - 文档导航：左侧固定目录，右侧内容
  - 搜索：命令面板风格（Cmd+K）
- **为什么好**：技术文档的设计标杆，好看且实用

### Raycast
- **URL**：raycast.com
- **风格对应预设**：A 极简黑白（深色）
- **可借鉴模式**：
  - Hero：产品截图为主，文字极少
  - 配色：深色 + 少量强调色
  - 动效：产品功能演示动画
  - 图标：统一填充风格，单色
- **为什么好**：效率工具的展示方式，用产品说话

## 使用方法

1. **确定项目类型** → 在上方分类中找对应案例
2. **看可借鉴模式** → 不是看整体，而是看具体哪个点值得抄
3. **结合预设** → 案例的配色/字体对应到你的风格预设
4. **提炼成代码** → 把模式写成自己的组件，不要截图照搬

> 记住：抄模式，不抄外观。同一个模式用不同的配色/字体/圆角，就是你的设计。
