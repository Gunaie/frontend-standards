# 场景范式：落地页 Hero 区

> Hero 区是用户看到的第一屏，决定了网站的第一印象。
> 本文档提供多种 Hero 布局范式，避免千篇一律的"标题+副标题+两个按钮+渐变背景"。

---

## 反模式提醒

❌ **禁止使用**以下公式化 Hero：
- 居中大标题 + 副标题 + 两个按钮 + 紫蓝渐变背景
- 标题每个字都渐变
- 满屏装饰性几何图形

---

## 范式 1：左文右图（产品预览型）

**适合**：有产品截图/演示的工具类产品。

```
┌─────────────────────────────────────────┐
│  导航栏                                    │
├─────────────────────────────────────────┤
│                                           │
│  ┌──────────────┐  ┌──────────────────┐  │
│  │  大标题        │  │                  │  │
│  │  副标题        │  │   产品截图/演示   │  │
│  │  [主按钮]      │  │                  │  │
│  └──────────────┘  └──────────────────┘  │
│                                           │
└─────────────────────────────────────────┘
```

**要点**：
- 左右比例约 1:1 或 6:4
- 右侧截图带圆角 + 细边框，不要加阴影
- 标题左对齐，不要居中
- 主按钮 + 次按钮，或只有主按钮 + 文字链接

**参考实现**：
```tsx
<section className="container mx-auto px-6 py-20">
  <div className="grid grid-cols-2 gap-12 items-center">
    <div>
      <h1 className="text-5xl font-bold tracking-tight text-text">
        让团队协作<br />更高效
      </h1>
      <p className="mt-6 text-lg text-text-secondary">
        一站式项目管理工具，让团队专注于真正重要的事情。
      </p>
      <div className="mt-8 flex gap-4">
        <button className="h-10 px-6 rounded-sm bg-accent text-accent-foreground font-medium">
          免费开始
        </button>
        <a href="#" className="h-10 px-4 flex items-center text-text-secondary hover:text-text">
          查看演示 →
        </a>
      </div>
    </div>
    <div className="rounded-lg border border-border overflow-hidden">
      <img src="/product.png" alt="产品预览" />
    </div>
  </div>
</section>
```

## 范式 2：居中纯文字（极简单品型）

**适合**：极简产品、单一功能工具、个人品牌。

```
┌─────────────────────────────────────────┐
│  导航栏                                    │
├─────────────────────────────────────────┤
│                                           │
│              大 标 题                      │
│           副 标 题 一 行                    │
│             [主按钮]                       │
│                                           │
│         小字：已有 XX 人使用               │
│                                           │
└─────────────────────────────────────────┘
```

**要点**：
- 标题不超过 8 个字，副标题不超过 20 字
- 只有一个主按钮，或主按钮 + 文字链接
- 大量留白，垂直居中
- 可以在背景加极淡的网格或噪点（可选）

**参考实现**：
```tsx
<section className="container mx-auto px-6 py-32 text-center">
  <h1 className="text-6xl font-bold tracking-tight text-text">
    极简，高效
  </h1>
  <p className="mt-6 text-xl text-text-secondary max-w-xl mx-auto">
    为专注而生的笔记工具。
  </p>
  <div className="mt-10">
    <button className="h-11 px-8 rounded-sm bg-accent text-accent-foreground font-medium">
      开始使用
    </button>
  </div>
  <p className="mt-6 text-sm text-text-muted">
    已有 10,000+ 创作者加入
  </p>
</section>
```

## 范式 3：全宽视觉 + 叠加文字（品牌展示型）

**适合**：品牌网站、创意产品、需要强烈视觉冲击的场景。

```
┌─────────────────────────────────────────┐
│  导航栏（透明）                            │
├─────────────────────────────────────────┤
│                                           │
│  [ 全宽背景图 / 视频 / 插画 ]              │
│                                           │
│     大标题（白色或深色）                   │
│     副标题                                 │
│     [按钮]                                 │
│                                           │
└─────────────────────────────────────────┘
```

**要点**：
- 背景图必须高质量，不用廉价图库
- 文字加一层半透明遮罩保证可读性
- 按钮用白色填充或描边
- 整体高度至少 100vh

## 范式 4：不对称布局（创意型）

**适合**：创意产品、设计工具、个人作品集。

```
┌─────────────────────────────────────────┐
│  导航栏                                    │
├─────────────────────────────────────────┤
│                                           │
│  大标题                                    │
│  ────────                                  │
│  副标题                          ┌──────┐  │
│  [按钮]                          │ 图片  │  │
│                                 │      │  │
│                                 └──────┘  │
└─────────────────────────────────────────┘
```

**要点**：
- 标题偏左，视觉元素偏右下
- 打破对称，但保持视觉平衡
- 用大留白引导视线

---

## Hero 区通用规则

1. **标题**：≤ 12 字（中文），字号 48px+，字重 700
2. **副标题**：≤ 25 字，字号 18px，颜色 `--text-secondary`
3. **按钮**：最多 2 个，1 主 1 次
4. **背景**：纯色为主，最多加极淡纹理，不用渐变
5. **高度**：桌面端 80vh ~ 100vh，移动端自适应
6. **导航栏**：Hero 区的导航栏可以是透明的，滚动后变实色背景

## 文案建议

- 标题用动词或结果，不要用名词堆砌
  - ❌ "智能协同办公平台"
  - ✅ "让团队协作更高效"
- 副标题说明"怎么做"，不是重复标题
- 按钮用动作词（开始、创建、体验），不要用"了解更多"
